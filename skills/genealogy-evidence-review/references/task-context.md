# Current task context

Apply this before working with materials. It requires no dedicated application,
project, state file or new register.

- **Mode.** Distinguish reviewing instructions, analyzing supplied material and
  external research. Reading or editing a skill does not itself authorize opening
  family records, running their checks or researching the family.
- **Currency.** Consider supplied current decisions, logs and working context
  together with the request. If an old copy and an identified current source
  exist, check the relevant current version within permitted access. Do not open
  other projects or all history for a routine single-file analysis. If currency
  cannot be checked, name that narrow gap; the first decision found is not
  automatically the current one.
- **Case and archive.** Establish which case the request and materials belong to.
  One explicitly supplied interview provides enough context. If several archives
  are available and the choice affects access or conclusions, clarify before
  dependent work. General rules may be shared; sources, people, IDs, accepted
  decisions, questions for the owner and search logs belong to their own case.
  Do not replace a missing family log with another family's log, even when names
  or IDs coincide. Do not transfer information between cases without a stated basis.
- **Authorization and scope.** Honor an existing, still-applicable authorization
  covering this case and work; do not request it again. General readiness for
  research does not resume deferred questions. External research requires both
  permission for that research and a specific current question. Unfinished local
  analysis does not itself prohibit an authorized search. Apply a newer decision
  within its scope, without extending it to other cases. Without authorization,
  or when search is prohibited, continue only independent work already authorized
  by the request; the prohibition itself does not authorize reading new material.

Then follow the selected skill's procedure. DNA, external-action, tree-change
and evidence-accuracy boundaries still apply. Do not introduce stage names,
private application commands or mandatory paths absent from the user's environment.
