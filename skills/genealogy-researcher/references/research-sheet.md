# Research sheet

Use the relevant rows; not every question needs every section.

## Question card

| Field | Contents |
|---|---|
| Objective | Event or identity match to establish |
| Starting information | Person, place, period, relatives; source of each material detail |
| Competing explanations | Candidates or alternative readings, not an averaged value |
| Distinguishing feature | What a new record could show to change the conclusion |
| Access | Supplied files, available tools and restricted routes |
| Resumption | Last action and condition for resuming an unavailable route |

## Select a record type

These are record-type suggestions, not claims that a particular archive holds them.

| Question | Possible records | Establish first |
|---|---|---|
| Parents | Birth/baptism, marriage, household records | Who reported the names and whose record was read |
| Two namesakes | Contemporary address, household or service records | Spouse, parents, address, occupation and incompatible simultaneous events |
| Migration | Population, passport, settlement, address records | Departure and arrival may be recorded by different institutions |
| Military history | Service records, orders, lists, personal papers | Unit, period, enlistment location; original contents separately from an index |
| Death/burial | Civil records, cemetery registers, inscriptions, notices | Which date refers to which event and who recorded it |

technical error; not yet performed. Specify pages, images or fields in the reading
column, rather than simply saying that a site was checked.

## Hand off a finding

Record a source once. Preserve relevant details and locators for each person
mentioned. On repeat access, compare the document with the previous result:
another link to the same scan is another access route, not another document.
Do not merge documents merely because their titles are similar.

For an ambiguous reading, give the original fragment, plausible alternatives
and a way to distinguish them. State when the image is unavailable; do not
reconstruct letters to fit a desired name. A reliable record about a candidate
does not establish that candidate's place in the researched family.
