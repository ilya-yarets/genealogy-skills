# Scope and external references

The MIT license covers the project's own instructions, code, configuration and
synthetic examples included in this archive. Each standalone skill carries the
same license. Copyright (c) 2026 Illia Yarats.

This distribution contains no historical archive scans, transcriptions or
source-derived historical evaluation excerpts. Earlier public-history tests
remain in the source project with their source-specific notices; they are not
relicensed or copied into this package. The examples here use invented people
and records. Original test responses are retained separately, not edited into
apparently successful evaluations.

Links to OpenAI, Anthropic and Agent Skills documentation identify external
references, not bundled or relicensed material. Host names belong to their
respective owners; this package is not an official host product or endorsement.

The GitHub source export references pinned versions of
[actions/checkout](https://github.com/actions/checkout) and
[actions/setup-python](https://github.com/actions/setup-python) in its CI workflow.
Their implementations are not bundled or relicensed here; GitHub retrieves them
under their own terms when the workflow runs. Preparing the workflow locally
does not execute or install those actions.

The organization of the installation/use README was informed by the public
[ex-USSR Kinship Research README](https://github.com/DenisSergeevitch/ex-ussr-kinship-research).
No code, instructions, assets or examples from that project are included here.
